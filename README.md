## 🚀 Key Features

- ⚡ **Instant Folder Generation**: Automatically creates standardized project folders:
  - `01.Project Files`
  - `02.Footage`
  - `03.Essential Elements`
  - `04.Sounds`
  - `05.Final Exports`
- 📌 **Remember Last Root**: Auto-persists and recalls your selected root directory across sessions.
- 🖱️ **Right-Click Integration**: Right-click anywhere in Windows Explorer or Desktop to spawn projects instantly. On Mac: Finder Quick Action (Tools menu) or drop a folder on the Dock icon.
- 🎨 **6 Dynamic Modern Themes**:
  - `🖥️ System Default` (Auto-detects Windows / macOS Dark & Light Mode)
  - `☀️ White (Light)` (Clean high-contrast mode)
  - `🌙 Black (Dark)` (OLED high-contrast dark mode)
  - `🌌 Cyber Blue`
  - `🔮 Synthwave Purple`
  - `🌲 Emerald Forest`
- 🔄 **In-App Auto-Updater**: Instant notification and seamless update download & install.
- 📁 **Automated Template Sync**: Automatically copies your preset project files, fonts, and assets into every new client project.
- ⌨️ **Keyboard Shortcuts**:
  - `Enter` : Create Project Now
  - `Ctrl + O` (Mac: `⌘O`) : Open Root Directory
  - `Ctrl + T` (Mac: `⌘T`) : Open Template Directory
  - `F5` : Check for Updates
  - `F2` : User Guide & Help
  - `F1` : About & Copyright

## 📥 Installation

### 🪟 Windows

1. Download **[Setup_FolderNest.exe](https://github.com/soykot539/Client-Project-Folder-Generator/raw/main/Setup_FolderNest.exe)**.
2. Run the installer and click **Install Now**.
3. Launch and start creating client projects in seconds!

### 🍎 macOS (11 Big Sur or later)

1. Download the DMG for your Mac:
   - **Apple Silicon (M1/M2/M3/M4)**: [FolderNest-macOS-arm64.dmg](https://github.com/soykot539/Client-Project-Folder-Generator/releases/latest/download/FolderNest-macOS-arm64.dmg)
   - **Intel**: [FolderNest-macOS-x86_64.dmg](https://github.com/soykot539/Client-Project-Folder-Generator/releases/latest/download/FolderNest-macOS-x86_64.dmg)
   - Not sure? Apple menu → About This Mac. "Chip: Apple M…" = Apple Silicon, "Processor: Intel" = Intel.
2. Open the DMG and drag **FolderNest** into **Applications**.
3. First launch: macOS will block it because the app is not notarized by Apple. Right-click FolderNest → **Open** → **Open**. On macOS 15+, go to System Settings → Privacy & Security → **Open Anyway**.
