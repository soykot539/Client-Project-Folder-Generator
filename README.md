## 🚀 Key Features

- ⚡ **1-Click Folder Generation**: Automatically creates standardized project folders:
  - `01.Project Files`
  - `02.Footage`
  - `03.Essential Elements`
  - `04.Sounds`
  - `05.Final Exports`
- 🖱️ **Windows Right-Click Integration**: Right-click anywhere in Windows Explorer or Desktop to spawn projects instantly.
- 🎨 **6 Dynamic Modern Themes**:
  - `🖥️ System Default` (Auto-detects Windows Dark / Light Mode)
  - `☀️ White (Light)` (Clean high-contrast mode)
  - `🌙 Black (Dark)` (OLED high-contrast dark mode)
  - `🌌 Cyber Blue`
  - `🔮 Synthwave Purple`
  - `🌲 Emerald Forest`
- 🔄 **In-App 1-Click Auto-Updater**: Instant notification and 1-click seamless update download & install.
- 📁 **Automated Template Sync**: Automatically copies your preset project files, fonts, and assets into every new client project.
- ⌨️ **Keyboard Shortcuts**:
  - `Ctrl + Enter` : Create Project Now
  - `Ctrl + O` : Open Root Directory
  - `Ctrl + T` : Open Template Directory
  - `F5` : Check for Updates
  - `F2` : User Guide & Help
  - `F1` : About & Copyright
